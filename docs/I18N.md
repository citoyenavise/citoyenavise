# Multilingue (i18n)

## Architecture

Frontend : i18next + React
Files : public/locales/{lang}/translation.json
Persistance : localStorage
URLs : /:lang/petitions, /:lang/elus, etc

## Ajouter traduction UI

1. Modifie public/locales/fr/translation.json
   ```json
   {
     "key": "Valeur français"
   }
   ```

2. Ajoute à public/locales/en/translation.json
   ```json
   {
     "key": "English value"
   }
   ```

3. Dans composant React :
   ```javascript
   import { useTranslation } from 'react-i18next';
   
   const MyComponent = () => {
     const { t } = useTranslation();
     return <h1>{t('key')}</h1>;
   };
   ```

4. npm test:i18n (vérifie intégrité)

## Traductions avec paramètres

JSON :
```json
"message": "Vous avez {{count}} signature(s)"
```

Component :
```javascript
{t('message', { count: 123 })}
```

Affiche : "Vous avez 123 signature(s)"
